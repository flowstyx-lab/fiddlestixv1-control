Notes

This GUI speaks the same text protocol as the V4 firmware: CMD:*, SET:*, TOGGLE:*, SAMP, SAMP2.
  • Flash the same FiddleStyxV4 .ino to both ends.
  • Use the on-stick long-hold (~6s within first 10s after boot) to swap Primary/Secondary roles.
  • This page should be opened in Chrome/Edge with Web Bluetooth enabled.
